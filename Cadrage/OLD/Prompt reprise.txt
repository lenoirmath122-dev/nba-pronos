## But de la reprise

Je veux reprendre le cadrage exactement là où il s’est arrêté.

Le projet est une application web privée de pronostics entre amis sur les **playoffs NBA**.

La stack cible prévue pour la vraie V1 est :

- Next.js ;
- Supabase ;
- Supabase Auth ;
- PostgreSQL ;
- RLS ;
- Vercel ;
- GitHub → Vercel ;
- Vercel Cron Jobs ;
- API NBA externe à terme.

Mais attention :

- le cadrage se fait ici dans Copilot ;
- le développement se fera plus tard dans Claude Project ;
- avant la vraie V1, on prévoit un **prototype jetable** ;
- le prototype utilisera une **simulation d’API NBA**, pas une API réelle.
