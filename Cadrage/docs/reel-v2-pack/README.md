## Repères de marque

- Fond `#191F2A` (dégradé `#1C2432` → `#171D28`), orange `#E8551F`, accent `#FF6B2B`, texte `#F5F7FA` / `#D7DBE0`
- Titres Oswald 700, texte Sora ; majuscules, 2 lignes max
- Zone de sécurité : éviter ~250 px en haut, ~400 px en bas, ~150 px à droite
- Handle `@panierballon.app` · lien `https://panierballon.fr`
- Vocabulaire : « pronostiquer », « prono », pas « parier / miser » ; aucune image de match NBA
